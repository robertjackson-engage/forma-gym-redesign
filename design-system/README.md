# Forma Gym Design System
Source of truth: `BRAND-KIT.md` (v1.2) + `docs/assets/css/main.css` tokens in `robertjackson-engage/forma-gym-redesign`.

- Foundations: colors, typography (Anton display · Montserrat body standing in for Proxima Nova · color-only accents)
- Components: buttons, cards, kinetic hero, forms, accordion/rows, stats/marquee bands, AI concierge

Regenerate: `python3` the generator in this folder's git history, or edit cards directly and re-run /design-sync.
